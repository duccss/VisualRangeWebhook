## VisualRangeWebhook

Small plugin that mimics Zeniths "Entered Visual Range" discord notif and sends it to a webhook. Optional @everybody ping. Useful on bots always afk at a base and allowing other base members to be notified when not in your bots discord server.

### Commands
`visualRangeWebhook` or `vrw`

```bash
visualRangeWebhook <on/off>
visualRangeWebhook webhook <url>
visualRangeWebhook everyoneMention <on/off>
```
